CubeVision X

Accessible computer vision app · CPE 018 final project

A desktop app that scans a Rubik’s Cube with a webcam and labels each sticker with a symbol, pattern or color name, so people with color vision deficiency can tell colors apart. It validates the scan, then guides the user to the solution step by step, with optional voice assistance.

  • Python
  • OpenCV
  • PySide6
  • NumPy
  • pyttsx3
